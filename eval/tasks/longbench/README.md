# LongBench tasks

Generated by `generate_tasks.py` from LongBench's own `config/dataset2prompt.json`
and `config/dataset2maxlen.json`, against the official dataset:

    https://huggingface.co/datasets/zai-org/LongBench

Data is expected at `../data/longbench/data/<task>.jsonl` — official schema,
`input` plus a raw `context`. The prompt lives here, in `doc_to_text`, which is
where LongBench puts it; a repackaged copy that bakes the prompt into `context`
will render it twice.

`metrics.py` is LongBench's scoring, unchanged.
